This is the actual image the CNN sees — frequency (mel scale) on the vertical axis, time on the horizontal axis, and color intensity for loudness (dB).

Model insights

Spectrogram

A spectrogram converts a 1-D audio waveform into a 2-D image showing which frequencies are present at each moment in time. We use the mel scale, which spaces frequencies the way human hearing perceives pitch, and a logarithmic (dB) intensity scale to mimic perceived loudness.

Convolution

A convolutional layer slides small learnable filters (e.g. 3×3) across the spectrogram image, each filter activating on a specific local pattern — a rhythmic pulse, a timbral texture, a frequency band. Stacking layers lets the network combine simple patterns into increasingly abstract ones.

Pooling

Max-pooling downsamples the feature maps after each convolution, keeping the strongest activations while discarding redundant spatial detail. This shrinks the data, adds translation tolerance (a beat shifted slightly in time still triggers the same feature), and reduces overfitting.

Feature extraction

Early conv layers learn generic patterns (edges, textures in the spectrogram); deeper layers combine these into genre-relevant concepts like "distorted guitar energy" or "steady four-on-the-floor kick". By the final conv block, each spatial location encodes a rich, high-level feature vector.

Global Average Pooling & Dense layers

Instead of flattening every pixel of the last feature map (which would explode the parameter count), Global Average Pooling reduces each channel to a single average value. A small dense layer then combines these into a genre decision.

Softmax & classification

The final layer outputs one score per genre, passed through softmax to turn them into a probability distribution that sums to 100%. The genre with the highest probability is the model's prediction — but the full distribution (shown as bars above) reveals how confident, or how torn, the model is.

Training vs. validation accuracy

Training accuracy measures fit on data the model has seen; validation accuracy measures generalization to unseen tracks. A growing gap between the two (training accuracy much higher than validation) signals overfitting — one reason this model uses dropout and batch normalization throughout.
